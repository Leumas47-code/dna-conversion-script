DNA & RNA Translator 🧬

A Python-based genetic sequence converter that translates between DNA, mRNA, tRNA, and amino acids.

Features
DNA to mRNA transcription
mRNA to DNA conversion
tRNA anticodon conversion
Codon-to-amino-acid translation
Multiple codon processing
Stop codon recognition
Basic sequence validation
Technologies
Python 3
Dictionaries
Functions
String manipulation
Genetic code mapping
Purpose

Created as an educational project to explore molecular biology concepts through Python programming.
